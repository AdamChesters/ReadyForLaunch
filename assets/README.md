# ReadyForLaunch artwork

Original artwork created for ReadyForLaunch. The icon uses a launch-arrow design;
`ReadyForLaunch.png` is the master and `ReadyForLaunch.ico` contains Windows sizes.
Run `scripts/build-icon.ps1` from the repository root to regenerate the ICO.
Artwork is distributed under the project's license. The app and installer use
the committed ICO; social artwork is used by the README.
