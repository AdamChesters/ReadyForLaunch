# ReadyForLaunch icon

Original ReadyForLaunch R/launch-arrow icon, created for Adam Chesters with OpenAI's built-in image generation tool on 9 September 2026. The visual reference was AdamChesters/PSVR2SimShaker's icon at commit 3ca53054bc1c32135f270f43a282f02087005ea4. The exact generation prompt is in icon-prompt.txt.

ReadyForLaunch.png is the generated master. ReadyForLaunch.ico contains 16, 24, 32, 48, 64, 128 and 256-pixel variants. Run scripts/build-icon.ps1 to rebuild the Windows icon from the PNG. The ICO is embedded in the executable and installer, and used by Windows for the taskbar, tray and shortcuts.
